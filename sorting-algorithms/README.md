1. Bubble Sort

Bubble Sort adalah algoritma pengurutan data yang bekerja dengan cara membandingkan dua elemen yang berdekatan, kemudian menukarnya apabila urutannya salah. Proses ini dilakukan secara berulang hingga seluruh data tersusun secara terurut dari kecil ke besar.

Algoritma ini disebut Bubble Sort karena nilai terbesar akan bergerak ke bagian akhir data seperti gelembung yang naik ke permukaan.

Cara penggunaan program Bubble Sort adalah dengan memasukkan data angka ke dalam list pada program, kemudian menjalankan file bubblesort.py. Setelah program dijalankan, hasil data yang sudah terurut akan ditampilkan pada terminal atau console.

Contohnya, jika data yang dimasukkan adalah:
5, 1, 4, 2, 8

Maka program akan mengurutkan data tersebut menjadi:
1, 2, 4, 5, 8

Bubble Sort cocok digunakan untuk pembelajaran dasar algoritma pengurutan dan data dengan jumlah kecil.

2. Binary Insertion Sort

Binary Insertion Sort adalah algoritma pengurutan yang merupakan pengembangan dari Insertion Sort dengan menggunakan Binary Search untuk mencari posisi penyisipan data secara lebih cepat.

Pada algoritma ini, setiap elemen akan dimasukkan ke posisi yang sesuai pada bagian data yang sudah terurut sebelumnya. Penggunaan Binary Search membantu mempercepat proses pencarian posisi dibandingkan pencarian biasa secara berurutan.

Cara penggunaan program Binary Insertion Sort adalah dengan memasukkan data angka ke dalam list pada file binarysort.py, kemudian menjalankan program tersebut. Setelah dijalankan, program akan menampilkan hasil data yang telah diurutkan.

Contohnya, jika data yang dimasukkan adalah:
9, 7, 3, 1, 6

Maka hasil pengurutannya menjadi:
1, 3, 6, 7, 9

Binary Insertion Sort memiliki proses pencarian posisi yang lebih efisien dibandingkan Insertion Sort biasa karena menggunakan metode Binary Search.
